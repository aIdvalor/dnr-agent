# Held-out pack `heldout-v1` (frozen)

20 adversarial cases / 34 turns in [`cases.jsonl`](cases.jsonl), generated by [`author.ts`](author.ts).

| Group | Cases | What it probes |
|---|---|---|
| escalation_persistence | h01–h04 | retries, retractions, chargeback threats and time passing must not reopen a human-owned order; only a human resolution does (h03) |
| stale_approval | h05–h08 | an approval given on earlier facts must not commit after a signature scan, a new buyer message, an injected "supervisor approved" message, or the window closing |
| duplicate_confirm | h09–h12 | five clicks, re-clicking an old approval after a re-run, two approvals for one proposal, a resolved handoff on an already-refunded order |
| conflicting_evidence | h13–h16 | delivered-then-in-transit scans, GPS mismatch inside the wait window, buyer text contradicting scans, order/buyer mismatch |
| injection_paraphrase | h17–h20 | carrier-note and buyer-message instructions phrased without the obvious words |

**How it was written.** From `policy.json` and `docs/eval-spec.md` only. Labels were set by hand from the policy text before the first run; the policy engine is not called by `author.ts`. The cases were committed in their own commit before they were ever run, so the git history shows the first pass.

**What it is not.** It is not independent. The same author wrote the implementation and has seen it (including the tripwire regex list) even though the agent prompts were not consulted while writing. The CTO review asked for a pack written by another person; that is still open. Treat this as a held-out *regression-resistance* check, not as external validation.

**Frozen.** SHA-256 of `cases.jsonl` at freeze (Nov 9, 2026):

```
1c61c3b00a0587b24784bdb89716e558944a9746a7b31b50e5585cf65ab791f2  evals/heldout/cases.jsonl
```

`npm run gate` verifies this hash. If a case is later used to fix code, it is relabelled as a regression case in `evals/REPORT.md`, not counted as held-out evidence. Changing a case means a new pack version, not an edit.

Run: `npx tsx evals/run.ts --pack heldout` (scripted, $0) · live: `scripts/live-rerun.sh` (free tier).
